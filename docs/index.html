全面完备的核心特性矩阵

拒绝繁琐与脆弱，专为低资源占用、高并发中继与无人值守流水线而生。

多协议下载引擎池

配置文件驱动驱动池与优先级（0-99）：内置 Aria2 RPC（BT/磁链）、Aria2 CLI Fork（多线程HTTP）、yt-dlp（流媒体视频）、Wget、Curl 与纯 Go Native 保底引擎。

内置夸克网盘 CLI (diskcli)

官方镜像集成作者开源的 diskcli，支持在下载完成后无缝触发命令行将文件自动极速上传至夸克网盘，转存成功后统一清理本地空间。

全生命周期 Hook 系统

首等公民级 Hook：on_create_failed（创建失败告警）、on_start（启动提醒）、on_progress（巡检进度广播）、on_complete（完成转存）、on_error（异常清理）。

多渠道广播通知矩阵

支持 Telegram Bot、企业微信、钉钉、飞书、Bark (iOS) 与通用 Webhook 并行并发推送，自动适配各平台专属 Markdown 与卡片排版。

进程崩溃自愈与断点接管

免外挂 DB（采用原子临时文件落盘），进程重启或断电恢复时自动执行 RecoverAndResume：离线完成的任务自动执行流水线，中断的任务自动断点续传（HTTP Range 206 / Aria2 continue）。

磁盘安全预留与防爆盘熔断

通过 OS 原生 Statfs 实时监控 Bavail 剩余块。任务提交时预检拦截（返回 HTTP 507），下载巡检时若可用空间低于预留安全线立即安全熔断中止，杜绝爆盘死机。

优雅的面向接口分层架构

高内聚、低耦合，各个模块支持插拔与 Mock 单元测试。

三分钟极速部署

选择您喜爱的方式一键启动 SkyHook。

推荐

方式 1：Docker 一键拉取运行 (预编译多架构镜像)

无需本地安装任何编译器与外部工具，直接拉取 GitHub 官方镜像：

docker run -d \
  --name skyhook \
  --restart unless-stopped \
  -p 8080:8080 \
  -p 6800:6800 \
  -e AUTH_TOKEN=your-secure-token \
  -e ENABLE_ARIA2_RPC=true \
  -e ARIA2_SECRET=your-aria2-token \
  -e QUARK_COOKIE="your_optional_quark_cookie" \
  -v $(pwd)/downloads:/data/downloads \
  -v $(pwd)/config:/data/config \
  ghcr.io/phpgao/skyhook:latest
编排

方式 2：使用 Docker Compose 一键启动

在克隆仓库后直接执行：

git clone https://github.com/phpgao/skyhook.git
cd skyhook/deploy
docker compose up -d
原生

方式 3：单一静态二进制原生运行

# 编译服务端与客户端
go build -o bin/skyhookd ./cmd/skyhookd
go build -o bin/skyhook ./cmd/skyhook

# 复制配置文件并启动
cp config.example.yaml config.yaml
./bin/skyhookd -c config.yaml

RESTful API 交互规范

简单标准，便于外部自动化系统、脚本或机器人集成。

端点 方法 鉴权 描述
/health GET 公开 健康检查接口，用于探测探针
/api/tasks POST Bearer Token 批量提交下载任务（支持普通 URL、Magnet 磁链、BT 种子）
/api/tasks GET Bearer Token 获取所有历史及正在运行的任务状态清单与进度
/api/tasks/:gid GET Bearer Token 精确查询指定任务 GID 的瞬时速度、百分比及落盘路径
